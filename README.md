# Word Blade 字刃勇者

英文打字冒險遊戲。怪物頭上掛著英文單字，打對一個字母，勇者就揮劍砍一下；打完整個字，怪物就被消滅。怪物走到勇者面前會扣血。

## 怎麼玩

- 直接用鍵盤打出怪物頭上的單字。**第一個字母**決定鎖定哪一隻怪物。
- `Backspace` 放棄目前目標，`Esc` 暫停，`Enter` 開始或繼續。
- 打錯會中斷連擊。連擊越高，分數倍率越高（最高 ×4）。
- 帶光環的特殊怪物：
  - ♥ 補血：回復 1 點生命
  - ❄ 冰凍：所有怪物停止 4 秒
  - ✸ 炸彈：消滅畫面上所有小怪
- 每一關最後都有魔王，要打出**整句英文**（包含空白）才能擊倒。

## 模式

| 模式 | 說明 |
| --- | --- |
| 冒險模式 | 5 個關卡：晨光森林、月影沼澤、冰晶洞窟、熔岩山脈、暗影城堡，每關一隻魔王。過關會解鎖下一關。 |
| 無盡模式 | 一波接一波，越來越快，每 5 波出現魔王。挑戰最高分。 |

難度分為簡單（約 20 WPM）、普通（約 35 WPM）、困難（50+ WPM）。

## 其他功能

- 單字附中文字義（可在選單關閉），邊玩邊背單字
- 即時顯示 WPM、正確率、連擊
- 結算畫面列出你最常打錯的字母
- 最高分與關卡進度存在瀏覽器的 localStorage
- WebAudio 合成音效，不需要任何音檔
- 支援手機（點畫面叫出鍵盤）
- 偵測到中文輸入法時會提醒切換成英文

## 執行

純 HTML／CSS／JavaScript，沒有建置步驟。直接用瀏覽器打開 `index.html` 即可，或用任何靜態伺服器：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

也可以直接開啟 GitHub Pages（Settings → Pages → 選擇分支與根目錄）。

## 檔案

```
index.html     頁面結構與選單
style.css      介面樣式
js/words.js    單字庫（三個難度階層＋魔王句子，含中文字義）
js/game.js     遊戲引擎：繪圖、怪物、輸入、計分、音效
```

想加自己的單字，編輯 `js/words.js`，格式是 `英文:中文`，用逗號分隔。
